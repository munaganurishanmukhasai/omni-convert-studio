# OmniConvert Studio

Free, private image and PDF tools that run entirely in your browser: convert images, make PDFs, PDF to images, enhance photos to 4K/8K, and change file size in KB.

Developed by Shanmuk — [Instagram](https://www.instagram.com/just_call_me_shanmuk__) · [LinkedIn](https://www.linkedin.com/in/munaganuri-shanmukha-sai-undefined-760150428)

## Put it online with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` (keep this exact name) and this README.
3. Go to Settings > Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-NAME.github.io/REPO-NAME/`.

## Get feedback in your email
Create a free form at formspree.io, copy its URL and paste it into `FB_ENDPOINT` in `index.html` (search for `FB_ENDPOINT`).
